# Deep Academia Fitness Center — Web Sitesi

Kuşadası Lena Park'taki Deep Academia Fitness Center için tek sayfalık tanıtım sitesi.

- Saf HTML, CSS ve JavaScript — derleme adımı ya da bağımlılık yok.
- Phive tarzı açılış bandı, kaydırmaya bağlı animasyonlar (fotoğraf yığını, "Derinlere dal" geçişi, ders kartları), yumuşak kaydırma.
- Yazı tipleri: Anton (başlıklar), Kanit (metin) — Google Fonts.

## Dosyalar

| Dosya | İçerik |
| --- | --- |
| `index.html` | Sayfanın tüm içeriği |
| `styles.css` | Tasarım ve animasyonlar |
| `app.js` | Slayt gösterisi, menü, kaydırıcılar, kaydırma animasyonları |
| `assets/` | Logo, fotoğraflar ve açılış videosu |

## Yerelde çalıştırma

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Yayın

GitHub Pages ile `main` dalının kökünden yayınlanır.
